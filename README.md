# Fully Associative Cache Practice

This is a small interactive practice tool for learning fully associative cache problems.

The tool randomly generates cache problems and lets users practice:

- Address breakdown
- Binary conversion
- Tag calculation
- Offset calculation
- Block start calculation
- Hit or miss tracking
- Cache line usage
- LRU replacement order
- Final cache state

## Features

- Generate a new random cache problem
- Show address sequence
- Fill in answers directly in the table
- Check answers automatically
- Highlight correct and wrong answers
- Reset all answers
- View the full answer key
- Practice LRU replacement in a fully associative cache

## Topics Covered

This practice tool helps with CS computer architecture topics such as:

- Cache memory
- Fully associative cache
- Block size
- Cache lines
- Address bits
- Offset bits
- Tag bits
- Hit and miss
- Cold cache
- LRU replacement

## How to Use

1. Open the HTML file in a browser.
2. Click **Generate New Problem** to create a new problem.
3. Fill in the answer boxes.
4. Click **Submit Answers** to check your work.
5. Click **Reset** to clear your answers.
6. Open **Show answer key** to review the solution.
